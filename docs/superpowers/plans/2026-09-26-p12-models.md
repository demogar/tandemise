## Self-review

- Precedence lives only in `resolveModel`; the executor gathers inputs and records its answer.
- A runtime that takes no model never has a model written on its run.
- `review.independent` is absent (not false) when either run is missing, so a gate reading it fails as unmeasured rather than pretending.
- No hardcoded model list anywhere (grep the diff for vendor names outside placeholders/tests).
