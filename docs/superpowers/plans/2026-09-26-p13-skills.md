# P13 plan: skills library

> For agentic workers: REQUIRED SUB-SKILL: superpowers:subagent-driven-development (or executing-plans). Steps use checkboxes.

**Goal:** import skills (a folder with `SKILL.md`) into a project's library by content hash, pin versions to roles and workflow steps, and give each run exactly its pinned versions — as `.claude/skills/<name>/` for runtimes that read a skills folder, or appended to the prompt otherwise — recording name, version and hash on the run.

**Spec:** `docs/superpowers/specs/2026-09-26-p13-skills-design.md`. Branch `feat/p13-skills-library`, base `feat/p12-model-routing` (#18).

**Architecture**
- Pure rules in `@tandemise/domain` (`entities/skill.ts`): hash, front matter, refs, pin resolution, prompt section, words, limits.
- Ports in domain: `SkillRepositoryPort` (SQLite), `SkillFilesPort` (scan / discover / git fetch / content store). The file side lives in the daemon (`apps/daemon/src/skill-files.ts`), like the workflow source, because it runs `git`.
- `SkillService` in application owns import, update, delete, role validation and pin resolution; the executor asks it for pins and content and does the materialising through the target's scoped filesystem.

**Global constraints:** `npm run ci` green; boundaries (no `child_process` in core; renderer `import type` only); design tokens only; migration 018 additive; comments say why; Conventional Commits.
