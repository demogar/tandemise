# Colour

Two layers. The **palette** is hues, derived from five brand anchors in OKLCH;
only the roles read it. The **roles** say what a colour is for, written once for
both themes as `light-dark(<light>, <dark>)`. Apps and components read roles
only: ask for `--status-failed` or `--accent`, never for "red" or a hex value.
